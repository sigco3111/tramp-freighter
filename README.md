## 게임 소개

버려진 화물선 한 척과 얼마 남지 않은 크레딧만 들고 솔 섹터에 떨어진 선장이 되어, 41일 안에 빚을 갚고 살아남는 것이 목표인 오픈 월드 우주 교역 게임입니다.

- **장르:** 스페이스 트레이딩 / 생존 시뮬레이션
- **플랫폼:** 웹 브라우저(데스크톱/모바일, 설치 없이 플레이)
- **플레이 방식:** 항성계 간 무역, 함선 관리, 이벤트 선택 기반 진행

## 게임 특징

- **유동적 시장 경제**: 항성계마다 상품 수급 상황이 실시간으로 달라져 이윤 창출 기회도 계속 변합니다.
- **정보 브로커**: 크레딧을 내고 시장 루머·가격 정보를 구매해 매매 판단에 활용할 수 있습니다.
- **함선 관리**: 선체·엔진·생명유지장치 상태를 관리하고, 정비와 부품 교체로 성능을 유지합니다.
- **연료와 도약**: 항성계 간 이동에는 연료가 필요하고, 도약 거리와 경로 계획이 생존을 가릅니다.
- **랜덤 이벤트**: 해적 조우, 고장, 축제 등 다양한 이벤트에 대응하는 선택지가 결과를 바꿉니다.
- **부채 시한**: 41일 안에 빚을 갚지 못하면 게임 오버입니다.
- **진행 저장**: 브라우저 로컬 저장으로 이어하기를 지원합니다.

## 한글화 범위

- UI, 대사, 이벤트, 상품/시스템 명칭 등 게임 텍스트 전반 한글 번역
- 정보 브로커 루머, 수리 비용, 상품 표기 등 조사(이/가, 을/를) 처리 포함
- 폰트/표시 레이아웃의 한글 표시 개선

## 플레이 방법

1. 상단의 플레이 링크를 엽니다.
2. 새 게임을 시작하고 초기 함선과 크레딧을 확인합니다.
3. 각 항성계의 무역소에서 싸게 사서 비싸게 팔며 자금을 불립니다.
4. 정보 브로커의 루머를 활용해 유망한 시장을 찾습니다.
5. 연료, 수리, 생활비를 감안해 41일 안에 빚 상환을 노립니다.

## 기술 스택

- Vite, Three.js 기반의 클라이언트 웹 게임
- Vitest 기반 단위/통합/속성 테스트 포함

## 빌드 및 로컬 실행

```bash
npm ci
npm run dev
```

브라우저에서 안내된 로컬 주소로 접속하면 개발 서버로 플레이할 수 있습니다.
